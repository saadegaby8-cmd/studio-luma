# Body

- Es una sola pieza: cuerpo entero o americano para que se vea completo; de costado para el
  calce en la cintura; de espalda (escote, cruce) con foto final.
- Detalles: escote, encaje, transparencias, broches.
- Beneficios: se usa como lencería o como top con jean o pollera (una toma con un jean puesto,
  arrancando ya vestida).
